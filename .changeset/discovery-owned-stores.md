Who may store under which DHT key. A `DHT_STORE` message may carry an optional proof `auth` (`signDhtStore`: the writer's Ed25519 key, a `seq`, an absolute expiry, and a signature over the key, the canonical value digest, `seq` and expiry); the stored value is unchanged, so readers of older nodes see what they always saw. `DhtNode` takes an opt-in `storePolicy`: in `mode: 'open'` an unsigned store is accepted as before unless the key is owned, and a verified proof owns a pod-id key (only that pod), a `stealth:<id>:shard3:<n>` key or an agent-anonymous 64-hex key (the first valid signer); in `mode: 'owned'` every store needs a proof and any key outside `openPrefixes` is owned by its first signer. An owned key is replaced only by its owner with a higher `seq`, and an entry never outlives its signed expiry. Bounded, named refusals (`value-too-large`, `store-full`, `writer-quota`, `rate-limited`, `lifetime-too-long`, `expired`, `stale-seq`, `owned-key`, `not-key-owner`, `unsigned-store`, `bad-auth`, `malformed`), counted in `storeStats` and passed to `onRefuse` with a short hash of the key and never the value. A node without a policy is unchanged (its `store()` now returns `{ stored: true }`); with one, a store answers with a promise and a ping reply carries `caps`. `StealthAgent` gains `ownedStores` (with an identity and shard format 3): each shard of an anonymous agent is stored under its own writer key derived from the identity (`deriveWriteSigner`, which refuses a non-deterministic signer), so the keys are unchanged and unlinked, group members who hold the lookup nonce can read but not store, and a refused store throws `store-refused`. New exports: `signDhtStore`, `verifyDhtStore`, `dhtStoreSigningBytes`, `deriveWriteSigner`, `canonicalJson`, `classifyStoreKey`, `podIdOfPublicKey`, `DHT_STORE_REFUSALS`, `DhtAuthError`.
