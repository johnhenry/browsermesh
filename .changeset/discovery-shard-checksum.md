Shard format 3, part one: a real checksum. `StealthAgent` takes `shardFormat` (`2` by default, which writes exactly what it always wrote; `3`, or `[2, 3]` to write both), `readFormats` (default `[2, 3]`) and the async `hideAsync()` / `reconstituteAsync()`. A format 3 shard record carries `checksum: "s256." + base64url(SHA-256(...))`, the whole digest over the shard's bytes, index, threshold, total, parity code and state length (no agent id, so an anonymous record names nothing). On the unsigned path it is a real corruption check where the character-code sum was not; on the signed path it is checked before the signature, so damage (`stats.shardCorrupt`) and a signer the reader does not trust (`shardBadSignature`) are counted apart, and the signature covers it instead of a separate data digest. Format 3 records are stored under different DHT keys (`stealth:<agentId>:shard3:<i>`, or the `lookup/3` label for anonymous keys), so an older peer never reads one and never mis-verifies it; a reader takes the newest complete write across both formats. Exports `stealthShardChecksum`. The synchronous `hide()` keeps writing format 2 and throws `async-required` if `shardFormat` includes 3.
